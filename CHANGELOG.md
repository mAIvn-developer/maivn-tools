## [2.0.0] - 2026-09-28

The 2.x line pairs with the maivn 2.0.0 SDK and mAIvn Platform v2. It is not a drop-in upgrade from 0.1.x.

### Changed
- Depends on maivn 2.x and maivn-contracts; maivn-shared is no longer used.
- Python 3.12 is the minimum.
- Extras select the document integrations: pdf, docx, workbooks, presentations, postgres, or all.
